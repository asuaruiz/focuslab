# Auditoría de Copywriting — Focus Labs Media Group

## Status Actual vs Potencial

Tu sitio tiene **buena base conceptual pero está sub-optimizado**. El contenido es minimalista (quizás demasiado) y deja dinero en la mesa en términos de persuasión y claridad de propuesta de valor.

### Análisis por Página

---

## 1. HOME PAGE ⚠️ CRÍTICO

### Estado Actual:
- **Fortalezas**: Concepto fuerte de "Certeza Estratégica", mensaje coherente
- **Debilidades**: 
  - Muy corto (solo 3 párrafos)
  - No diferencia contra competencia
  - Falta "proof" de competencia (números, resultados, testimonios)
  - No hay CTA explícito excepto botón pequeño al final
  - No responde "¿por qué yo y no otra productora?"

### Mejoras Propuestas:

**1. Expandir Hero Copy**
```
ACTUAL:
"Certeza Estratégica en una Industria Ruidosa"

PROPUESTO:
"Cuando tu marca necesita contar una historia que importa.
No una fábrica. Un compañero estratégico."
```

**2. Agregar sección de "Por Qué Somos Diferentes"**
- Comparación: Videógrafo casual vs Productor Estratégico
- Tu proceso: Intención → Claridad → Confianza → Resultados
- Estadísticas o KPIs (clientes que escalaron, satisfacción, ROI)

**3. Agregar Social Proof**
- Logos/nombres de clientes (con permiso)
- 2-3 testimonios muy breves pero poderosos
- Números: "100+ projects", "X years of experience", etc.

**4. Expandir "Certeza Estratégica"**
- Explicar qué es (actualmente es vago)
- Mostrar ejemplo: Antes/Después
- Conectar con dolor del cliente ("Estás cansado de...")

**5. Agregar CTAs Múltiples**
- "Explorar Servicios" (ya existe)
- "Ver Casos de Estudio" (new)
- "Conocer Nuestra Filosofía" (new)
- "Contacta para Consulta Gratis" (new)

**Largo propuesto**: 800-1000 palabras (vs actual ~200)

## 2. FILOSOFÍA PAGE ✅ BUENA pero EXPANDIBLE

### Estado Actual:
- **Fortalezas**: Estructura clara, principios definidos, coherencia
- **Debilidades**:
  - Principios son muy cortos (1 línea cada uno)
  - Falta narrativa sobre "por qué esto importa"
  - No explica cómo estos principios se traducen en trabajo
  - Misión/Visión son abstractas

### Mejoras Propuestas:

**1. Expandir Introducción**
Agregar párrafo que cuente:
- Historia de por qué existen (origin story)
- Qué problema resuelven
- Cómo ven el mundo diferente

**2. Expandir Cada Principio**
```
ACTUAL (Intencionalidad):
"Todo comienza con un propósito. La intención crea claridad, 
y la claridad crea confianza."

PROPUESTO:
"INTENCIONALIDAD
Todo comienza con un propósito. No es sobre tener una cámara cara 
o seguir tendencias. Es saber exactamente qué quieres comunicar 
antes de grabar un fotograma.

La intención crea claridad. La claridad elimina la fricción. 
El cliente no está nervioso porque sabe exactamente qué esperar. 
El equipo ejecuta con precisión porque entiende el objetivo. 
El resultado final resuena porque fue deliberado.

Cuando trabajas con nosotros, cada decisión tiene una razón. 
No es capricho. No es seguir tendencias. Es propósito puro."
```

**3. Agregar "Cómo Se Vive Esto"**
Sección que explique cómo cada principio se manifiesta en el trabajo real:
- En el set
- En las conversaciones con clientes
- En el proceso de edición
- Etc.

**4. Mejorar Misión/Visión**
Hacerlas más específicas y emotivas.

**Largo propuesto**: 1500-2000 palabras (vs actual ~700)

## 3. SERVICIOS PAGE ⚠️ INCOMPLETO

### Estado Actual:
- **Fortalezas**: Gridded, visualmente limpio
- **Debilidades**:
  - Descripción de servicios muy corta
  - No explica qué esperar de cada uno
  - Falta información sobre proceso
  - Precios solo muestran "starting at"
  - No hay diálogo con cliente (pain points, soluciones)

### Mejoras Propuestas:

**1. Expandir Intro**
```
"No ofrecemos menús genéricos. Ofrecemos soluciones arquitectónicas 
para diferentes etapas de tu negocio.

Si estás explorando video, te ayudamos a descubrir qué funciona.
Si necesitas escala, construimos un pipeline de contenido estratégico.
Si buscas posicionamiento, convertimos líderes en autoridades."
```

**2. Para Cada Servicio**:

**A. Descripción Expandida**
- Qué es (1-2 párrafos)
- Para quién es
- Qué problema resuelve
- Qué esperar (timeline, deliverables)

**B. Formato de Presentación**
```
SERVICIO: [Nombre]
Para: [Tipo de cliente]
Resultado: [Lo que ganan]
Incluye: [Elementos específicos]
Timeline: [Duración]
Inversión: [Rango de precio]

[Descripción persuasiva 150-200 palabras]
```

**3. Agregar Casos de Estudio Inline**
Pequeños ejemplos de cada servicio en acción

**4. Agregar Preguntas Frecuentes**
"¿Cuál servicio necesito?", "¿Cuánto cuesta?", etc.

**Largo propuesto**: 2000-2500 palabras (vs actual ~400)

## 4. EXPERIENCIA DE CLIENTES PAGE ✅ BUENA

### Estado Actual:
- **Fortalezas**: Journey mapping es claro, pasos lógicos
- **Debilidades**:
  - Descripción de cada paso muy corta
  - No explica "por qué" cada paso importa
  - Falta narrativa sobre transformación del cliente
  - Testimonios no están "vivificados"

### Mejoras Propuestas:

**1. Expandir Cada Paso del Journey**
```
ACTUAL (Descubrimiento):
"Escuchamos antes de cotizar para entender qué intentas lograr."

PROPUESTO:
"DESCUBRIMIENTO: Escuchamos Primero
Cuando te contactas, no recibas un presupuesto automático. 
Recibas una conversación real.

Nos importa entender:
- ¿Cuál es tu verdadero objetivo? (no solo "quiero un video")
- ¿Quién necesita ser persuadido?
- ¿Qué cambio quieres en cómo te perciben?
- ¿Cuál es tu historia más importante?

Esta fase toma 30-60 minutos. No es venta. Es investigación. 
Es cómo sabemos si somos el equipo correcto para ti."
```

**2. Agregar "La Experiencia Emocional"**
Entre pasos técnicos, agregar cómo se siente el cliente:
- ¿Está confiado?
- ¿Sabe qué esperar?
- ¿Se siente cuidado?

**3. Mejorar Sección de Testimonios**
Agregar:
- Nombre + Cargo + Empresa
- Contexto: "Trabajamos con X en..."
- Testimonio (1-2 párrafos)
- Resultado cuantificable si posible

**4. Agregar "Lo Que Los Clientes Dicen Después"**
Sección que muestre impacto a largo plazo:
- Cómo cambió su negocio
- Cómo cambió su percepción
- Qué harían diferente (nada)

**Largo propuesto**: 1200-1500 palabras (vs actual ~600)

## PRINCIPIOS DE COPYWRITING APLICADOS

✅ **Claridad sobre cleverness**: Explicar qué haces antes de ser sofisticado
✅ **Beneficio sobre features**: No "grabamos en 4K", sino "Te ves como un líder"
✅ **Narrativa sobre listas**: Historias convencen; listas informan
✅ **Empatía**: Nombrar el problema antes de la solución
✅ **Especificidad**: "El 78% de nuestros clientes..." vs "Muchos clientes..."
✅ **CTA múltiples**: Diferentes puntos de entrada para diferentes clientes
